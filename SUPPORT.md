# Getting Help with ColdBrew

## Documentation

Start with the official documentation at **[docs.coldbrew.cloud](https://docs.coldbrew.cloud)**:

- [Getting Started](https://docs.coldbrew.cloud/getting-started) — Create your first ColdBrew service
- [How-To Guides](https://docs.coldbrew.cloud/howto) — Step-by-step guides for common tasks
- [Integrations](https://docs.coldbrew.cloud/integrations) — Set up New Relic, Prometheus, Sentry, and more
- [Packages](https://docs.coldbrew.cloud/packages) — API reference for all ColdBrew packages

## Asking Questions

- **GitHub Discussions** — For questions, ideas, and general discussion, use [GitHub Discussions](https://github.com/go-coldbrew/core/discussions) on the core repo
- **Stack Overflow** — Tag your question with `coldbrew` and `go`

## Reporting Bugs

Found a bug? Open an issue on the **specific package's repository**:

- [core](https://github.com/go-coldbrew/core/issues)
- [interceptors](https://github.com/go-coldbrew/interceptors/issues)
- [errors](https://github.com/go-coldbrew/errors/issues)
- [log](https://github.com/go-coldbrew/log/issues)
- [tracing](https://github.com/go-coldbrew/tracing/issues)
- [options](https://github.com/go-coldbrew/options/issues)
- [grpcpool](https://github.com/go-coldbrew/grpcpool/issues)
- [data-builder](https://github.com/go-coldbrew/data-builder/issues)

Not sure which package? Open it on [core](https://github.com/go-coldbrew/core/issues) and we will triage it.

## Security Issues

**Do not open public issues for security vulnerabilities.** See [SECURITY.md](SECURITY.md) for responsible disclosure instructions.
